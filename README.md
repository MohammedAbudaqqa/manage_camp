# نظام إدارة المخيم

موقع لإدارة الأسر في المخيم (تسجيل الأسر، الأفراد، المساعدات، التصدير والاستيراد عبر Excel).

- الملف الرئيسي: `index.html` (يجب أن يبقى بهذا الاسم في جذر المستودع).
- `xlsx.full.min.js`: مكتبة Excel (مضمّنة ليعمل الموقع بدون اعتماد على مواقع خارجية).
- البيانات تُحفظ في متصفح كل جهاز فقط ولا تُرفع إلى GitHub.

**تحذير:** لا ترفع ملفات النسخ الاحتياطية أو ملفات Excel التي تحتوي على بيانات الأسر إلى المستودع.
